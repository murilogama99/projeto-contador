O projeto foi construído utilizando as seguintes tecnologias web fundamentais:
* **HTML5** - Estruturação do conteúdo das páginas.
* **CSS3** - Estilização, layout, cores e responsividade.
* **JavaScript** - Lógica das aplicações

## 📁 Estrutura do Repositório
A organização dos arquivos neste repositório está estruturada da seguinte forma:
* `index.html` - Página principal do site.
* `info.html` - Página de informações do site.
* `contato.html` - Página contendo formulário para contato.
* `sobre.html` - Página contando sobre o site.
* `ingresso.html` - Página contendo os ingressos.
* `css/` - Pasta contendo os arquivos de estilização (`style.css`).
* `images/` - Pasta com as imagens e artes utilizadas no site.
* `js/` - Pasta contendo arquivos da parte lógica do site.
